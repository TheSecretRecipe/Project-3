# Chess-Players-Searcher
Project 3 for COP3530 (Data Structures and Algorithms)

Instructions for running the code:
1. Install the CLion IDE if not already installed.
2. Install SFML (Simple and Fast Multimedia Library), unzip it, and move it into your CLion projects file.
3. Download the Blitz Player Directory file and move it into your CLion projects file (with SFML).
4. Open the main.cpp in the Blitz Player Directory file either through your file system or in CLion.
5. Run main.cpp! :)

Notes:
This is an open-source project, so feel free to modify and redistribute the program code.
Files for the CSV data, fonts, and imagery used in the program are located in their own separate folders in the cmake-build-debug file.
While this program was created in the CLion IDE, it can be run in VSCode or other IDEs using specialized integrations.
